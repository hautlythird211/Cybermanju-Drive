Key Architectural Patterns

Triple-Mode IPC (useTauri.ts)

The frontend communicates with the backend via a three-tier fallback:

1. Tauri Conduit IPC (2.4x faster) — desktop app with `window.__TAURI__`
2. WASM bridge (IndexedDB) — browser with WASM support
3. REST API (HTTP fetch) — Web Dashboard on port 3456

Cross-Crate Dependencies

cybermanju-types ──► ALL crates (root types)
cybermanju-portable-db ──► types + crypto + compression + db
src-tauri ──► ALL workspace crates (orchestrator)
cybermanju-drive-wasm ──► standalone pure Rust (no C bindings)

Data Flow

Import → FileNode in redb + Tantivy index → Encrypt (ML-KEM) → Compress
(LZ4→Zstd→Brotli) → Face detect (auto-cluster) → Sync to backends
(compress→preview→upload→link) → Portable DB → Trash/Share/Version

Build Commands

npm run typecheck # TypeScript type checking
npm run rust:check # Cargo check (all crates)
npm run rust:clippy # Cargo clippy lints
npm run rust:test # Run all Rust tests
npm run check:all # TypeScript + cargo check + clippy
npm run tauri:build # Production desktop installer
npm run build:wasm # WASM/GitHub Pages build
docker build -t cybermanju-drive:latest . # Docker image
docker compose up -d # Run with Docker Compose
